# TodoList

A simple and interactive **Todo List** application built with **React**. This app helps users manage their daily tasks efficiently by allowing them to add, delete, and mark tasks as completed.

## Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- User-friendly interface

## Tech Stack
- Frontend: React
- Styling: CSS
